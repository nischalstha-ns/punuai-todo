# PunuAI Todo

A simple, clean Todo list app built with Flutter.

## Features
- Add new tasks
- Mark tasks as done / undone
- Delete tasks (swipe or delete button)
- Tasks persist on the device (shared_preferences)

## Getting started
1. Install [Flutter](https://docs.flutter.dev/get-started/install)
2. Run `flutter pub get`
3. Run `flutter run` (or `flutter build apk --release` for an installable APK)

## Project structure
- `lib/main.dart` — the whole app (UI + storage)
- `android/` — Android project files
